Mathematical & Miscellaneous Algorithms
- Find Peak Element: Identifies an element in an array (1D) or matrix (2D) that is greater than or equal to its neighbors. Utilized in optimization problems for finding local maxima efficiently in logarithmic time.
- Magic Square: A square matrix where the sums of rows, columns, and diagonals are equal. The placement of numbers follows specific patterns, making it useful in cryptography and mathematical puzzles.
- Cosine Similarity: Measures the cosine of the angle between two non-zero vectors. Often used in natural language processing (NLP) and recommendation systems to determine the similarity between text documents.
- Jaccard Similarity: Compares the similarity and diversity of two sets by dividing the size of the intersection by the size of the union. Commonly applied in clustering and machine learning.

- Binary Search: Efficiently searches for an element in a sorted array by repeatedly dividing the search interval in half. Achieves a logarithmic time complexity, making it ideal for large datasets.
- Max-Min Problem: Finds the maximum and minimum values in an array using divide and conquer, which is faster than brute force approaches.
- Strassen’s Matrix Multiplication: A faster matrix multiplication algorithm that reduces computational complexity from O(n³) to approximately O(n².81), useful in numerical computations and scientific simulations.

Greedy Algorithms
- Activity Selection: Selects the maximum number of non-overlapping activities or events, making it widely used in scheduling problems.
- Knapsack Problem: Optimizes the selection of items to maximize value within a weight limit. Items can be chosen fractionally for a more efficient approach. Applied in resource allocation and financial optimization.
- Dijkstra’s Algorithm: Finds the shortest path from a source node to all other nodes in a graph. Used extensively in network routing, GPS systems, and pathfinding.
- Prim’s and Kruskal’s Algorithms: Both find the minimum spanning tree of a graph, critical in network design problems such as laying cables or constructing road networks.

Dynamic Programming (DP)
- Floyd-Warshall Algorithm: Computes shortest paths between all pairs of nodes in a graph with O(n³) complexity, making it suitable for dense graphs.
- 0/1 Knapsack Problem Using Set: Solves the traditional 0/1 knapsack problem while optimizing space usage via a set data structure, valuable in space-constrained optimization tasks.
- Traveling Salesman Problem (TSP): Determines the shortest route visiting each city exactly once using DP and bitmasking. Extensively applied in logistics and delivery route planning.
- Matrix Chain Multiplication: Minimizes the number of scalar multiplications required to compute the product of matrices. Used in database query optimization and compiler design.


Backtracking
- N-Queens Problem: Places N queens on an N×N chessboard such that no two queens threaten each other. Uses recursive exploration and pruning to discard invalid placements. Applied in combinatorial problems and AI.
- Graph Coloring Problem: Assigns colors to graph nodes such that no two adjacent nodes share the same color, addressing scheduling issues and register allocation in compilers.
